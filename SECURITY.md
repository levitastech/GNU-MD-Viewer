# Signaler une vulnérabilité

GNU-MD Viewer ouvre des fichiers potentiellement non fiables. Ne publiez pas de détail exploitable ou de document privé dans une issue publique.

Avant publication du dépôt, les mainteneurs doivent activer **Private vulnerability reporting** dans les paramètres GitHub et renseigner ici l'adresse ou le canal privé officiel. Tant que ce canal n'est pas configuré, ce document ne prétend pas fournir un moyen de signalement confidentiel.

Une fois le dépôt public et le canal activé, utiliser l'onglet **Security → Report a vulnerability** du dépôt. Inclure les versions, système, reproduction minimale expurgée, impact et proposition éventuelle ; éviter toute donnée personnelle. Les mainteneurs accusent réception et coordonnent une correction et un avis de sécurité avant divulgation, selon les moyens disponibles. Aucune durée de réponse n'est garantie pour l'instant.

Modèle de menace et invariants techniques : [docs/SECURITY.md](docs/SECURITY.md). Les versions prises en charge seront indiquées ici à partir de la première release.
