# Code de conduite

Ce projet accueille les contributions respectueuses, quels que soient l'expérience et le parcours. Rester factuel et constructif ; éviter insultes, harcèlement, attaques personnelles, divulgation de données privées et comportements discriminatoires.

Les mainteneurs peuvent modérer les échanges et écarter un contenu ou une contribution qui enfreint ces règles. Une décision de modération devrait être expliquée et proportionnée ; les signalements privés seront traités de manière discrète dans la mesure du possible.

Avant l'ouverture publique du dépôt, les mainteneurs doivent désigner un canal de contact privé pour les signalements de conduite ; ne pas utiliser les issues publiques pour exposer une personne. Ce texte ne promet ni confidentialité absolue ni délai de réponse garanti.
